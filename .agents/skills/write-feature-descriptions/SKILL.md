# Write Feature Descriptions

Gebruik deze structuur:

## Feature Title

## User Problem

## Desired Outcome

## Target Users

## Functional Description

## Scope In

## Scope Out

## Acceptance Boundaries

## Candidate User Stories

## Constraints

Noem product-, UX-, accessibility-, content-, security- en architectuurgrenzen.

## Readiness

Kies: Ready for user story writing, Not ready clarification required, of
Escalation required.

Houd de feature klein genoeg om door afzonderlijke stories geleverd te worden
en maak afhankelijkheden en ontbrekende beslissingen zichtbaar.
