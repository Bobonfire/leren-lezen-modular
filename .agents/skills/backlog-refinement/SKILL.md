# Backlog Refinement

Beschrijf:

- type werkitem;
- productdoel;
- persona of stakeholder;
- gewenste uitkomst en business value;
- scope in en scope out;
- afhankelijkheden;
- risico's en onzekerheden;
- prioriteit met reden;
- voorgestelde uitvoerende agent;
- readiness status.

Splits een item wanneer het meerdere onafhankelijke uitkomsten of agents bevat.
Beperk bugfixes tot herstel van eerder goedgekeurd gedrag.

Kies exact een beslissing:

- Ready for epic description
- Ready for feature description
- Ready for user story writing
- Ready for handoff
- Not ready, clarification required
- Escalation required
