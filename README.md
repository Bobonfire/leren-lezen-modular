# 📚 Leren Lezen

Een eenvoudige maar speelse webapplicatie om kinderen te helpen bij het leren lezen.  
De app biedt verschillende spelmodi zoals **emoji-woorden raden** en **CVC-woordjes bouwen**, gecombineerd met beloningen, sterren en streaks om motivatie hoog te houden.

## Lokaal starten

Open `index.html` rechtstreeks in de browser. De gegenereerde browserbundle in
`public/app.js` zorgt dat de vier leerknoppen ook zonder lokale webserver werken.

Na wijzigingen onder `src/`:

```bash
node scripts/build-browser-bundle.mjs
```
